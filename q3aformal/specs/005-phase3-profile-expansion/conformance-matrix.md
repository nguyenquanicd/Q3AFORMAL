# Phase 3 four-state conformance matrix

Revision 0.3 describes the opt-in `Q3A-FOUR-STATE-DEVELOPMENT` profile in the Windows r12 preview. Source fixtures exercise the parser, elaborator, lowering, and replay against the exact packaged executable. The model audit regenerates the versioned Transition Intermediate Representation (T-IR) and compares its canonical digest to the evaluated and queried model identities. Its structural checks cover timing, operator nodes, width, signedness, index bounds, instance wiring and sampled history. The structural audit checked 87 typed expression nodes in 11 source fixtures, six temporal layouts, seven division and remainder equations, two linked history registers, and the first-match guard. It matched 427 runtime reports to regenerated model identities. Six controlled changes to bounds, type, operator, provenance or history wiring each caused rejection. The current rows summarize exercised construct families. Release review still needs to confirm syntax-level completeness and approve the selected profile. ## Revision 0.2 additions in the r11 preview

| Added construct | Expected lowered behavior | Positive and boundary evidence | Negative evidence or documented limit |
| --- | --- | --- | --- |
| Packed division and remainder | Apply the common context width and signedness. Signed division truncates toward zero and nonzero remainders follow the sign of the dividend. A zero divisor or indeterminate operand yields all X bits in an RTL expression. | All 256 two-bit input pairs, 64-bit signed overflow, checked certificates, sampled replay and a quotient used as a delay. [Division](../../evidence/r11/profile-check/four-state-divide/qualification.json) | Baseline division and division by zero in a constant delay are rejected. |

[Named sequences](../../evidence/r11/profile-check/four-state-named_sequence/qualification.json) | Baseline use, unresolved references, name collisions, arguments and referenced recursion are rejected. |
