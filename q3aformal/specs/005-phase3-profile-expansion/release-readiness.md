## Trace format decision

Product decision OD-04 in specification §18 covers the native trace schema and the need for Fast Signal Trace (FST). The proposed release scope is indexed native trace version 1 for supported two-valued witnesses and the in-process Value Change Dump (VCD) codec for interchange. The four-state evidence uses the corresponding profile commands and versioned witness formats. The specification makes FST optional until its profile and interoperability corpus are approved. The owner approved native trace version 1 and VCD for revision 16 and kept FST optional. [OD-04 approval](../../evidence/r16/owner-decisions.json)

Native version 1 uses little-endian integers and identifies itself with the `Q3ATRC1` header. Signal identifiers are ordinals in the file's ordered dictionary. Each 256-frame block stores one checkpoint value per signal and subsequent changes. The block index and per-signal offsets permit selective reads. The indexed file stores the property, candidate frame and signal values. The run bundle carries source, replay and assumption provenance. The documented native reader limits are 10,001 frames, 100,000 signals, widths of 1 to 64 bits and a 16 MiB name dictionary. [Native trace contract](../003-phase1-block-mvp/plan.md#indexed-witness-traces) · [VCD contract](../003-phase1-block-mvp/plan.md#vcd-import)

The exact r15 executable reopened two earlier Phase 1 bundles and their two r15 equivalents. All 52 sampled values matched the saved replay records. Source-required reopening revalidated each model and indexed trace, and also checked both saved counterexample VCDs. The reader rejected a file carrying an unsupported format header. The r15 regression also verified selective reads across a block boundary and VCD round-trip behavior. ## Replay performance evidence

The exploratory run used the frozen 321-frame Register-Transfer Level (RTL) witness and a 129-frame four-state witness for the nested `first_match` cover property. The latter replayed attempt 0, match 2, and all 129 frames. Each workload ran three times in a fresh process for revision 12 and for the diagnostic build with measurement off and on. Recorded identities bind the executable, inputs, source-backed bundle and witness. The original waveform was validated as a separate stage. The 10,001-frame synthetic Graphical User Interface (GUI) trace measures indexing and viewport rendering. [Frozen trace definitions](../../prototype/benchmark/phase1-debug-limits.approved.json) · [Raw diagnostic data](../../evidence/p3-replay-timing-build/diagnostics-on/qualification.json)

| Stage median | 321-frame bounded witness | 129-frame four-state witness |
| --- | ---: | ---: |
| Regenerate the source model | 1.75 ms | 5.67 ms |
| Regenerate the query and verify its Conjunctive Normal Form (CNF) identity | 137.48 ms | 6.53 ms |
| Decode the witness | 0.44 ms | 0.32 ms |
| Evaluate RTL and check the property | 0.47 ms combined | 0.70 ms RTL and 0.67 ms property |

Diagnostic output uses standard error when `Q3A_REPLAY_TIMING=1`. Each measured command wrote identical standard output with diagnostics off and on. The 321-frame bundle also matched revision 12 byte for byte. The four-state command matched revision 12 after excluding the two hashes that bind evidence to the originating build. The diagnostic source build passed all 30 four-state regressions and the source-required bundle regression. The raw reports retain launch-time variability and sampled process-tree working set. [Collector](../../prototype/benchmark/measure_phase3_replay.py) · [Comparison](../../evidence/p3-replay-timing-build/comparison.json) · [Source-build qualification](../../evidence/p3-replay-timing-build/qualification.json)

The measured RTL evaluator accounted for a small share of reopening time on both fixtures. Keep the interpreter for this profile. The query-regeneration cost on the 321-frame fixture warrants attention if later subsystem measurements show that reopening misses its performance target. Query and source identity checks still apply. These exploratory timings provide the §16.4 replay evaluation and carry no Q3AF-AC-17 verdict.
