# Q3AFormal Product Requirements Traceability

This inventory records existing evidence and remaining acceptance work against [specification revision 0.10](../002-phase0-feasibility/proposed/Q3AFORMAL_SPECIFICATION_v0.10.md). Requirement and acceptance identifiers abbreviate the `Q3AF-` prefix. Phase 0 evidence applies to the approved Gate A profile. Phase 1 proof paths use the one-clock, two-valued model. Evidence links can identify a recorded result or a runnable regression. A runnable regression alone does not close acceptance. Read this matrix with the [Phase 1 workstream decisions](plan.md).
