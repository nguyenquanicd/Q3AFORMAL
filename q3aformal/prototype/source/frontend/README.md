# Q3AFormal Frontend

The Phase 0 frontend contains a source-located lexer, recursive-descent syntax validator, and an early elaborator. The parser validates the implemented corpus grammar and retains token spans plus declaration, generate, instance, continuous-assignment, partial procedural statement trees, and source spans for SVA property declarations/checks. It is not a complete SystemVerilog abstract syntax tree; the lowerer translates only the documented SVA subset into structured temporal T-IR and symbolic sequence automata, not executable property monitors or solver-ready transition predicates.

`--lex`, `--parse`, and `--parse-project` provide lexical/syntax checks. `--elaborate-project` resolves the selected top module's typed parameters, localparams, ports, signals, static generate conditions/iteration counts, and recursively elaborates child-module instances in ordinary and active generate scopes. Connected hierarchy ports must have exact widths, and recursive module instantiation is rejected. The current port-expression width evaluator covers identifiers/constants, bit/part selects, concatenation, unary/binary operators, and conditional expressions in the parsed subset; it is not a complete IEEE 1800 expression type/sizing implementation.

The unbased unsized fill literals `'0` and `'1` take the resolved width in context-determined expressions and one bit in self-determined positions. Unbased unsized `'x` and `'z` forms are rejected with a source-located diagnostic. `test_fill_literal_context.ps1` checks direct assignments and rejection. `test_fill_expression_context.ps1` checks compound expressions, port contexts and clocked state.

The T016 lowerer represents unsized decimal literals as signed values with at least 32 bits, uses assignment context for focused literal-only and mixed signal/decimal unary/binary +/− expression trees, and emits an explicit `assignment_resize` T-IR node when a narrow destination truncates the expression. Wider contexts are passed to unsized decimal leaves. The RTL-005 regressions check continuous, `always_comb`, and `always_ff` assignments with signed and unsigned signals. Direct sized binary/octal/decimal/hex literals support assignment zero/sign extension and truncation in continuous, always_comb, and always_ff contexts under RTL-006; general sized-literal operator context propagation, other mixed operators, arbitrary expressions, and complete IEEE 1800 sizing remain unsupported. See the [RTL-006 evidence](../../corpus/results/t017-rtl006-sized-literal-conformance-2026-11-20.md), [RTL-005 progress report](../../evidence/conformance/rtl-005-decimal-context-2026-11-19.md), and [mixed-context evidence](../../evidence/conformance/rtl-005-mixed-decimal-context-2026-11-19.md).

The Phase 0 parser rejects `>>>` at the operator's source location. The SAT bit-blaster and witness replay retain internal support for previously generated typed models and the [proposed extension](../../corpus/results/t017-rtl017-arithmetic-right-shift-extension-2026-11-20.md).

Elaboration is partial: active generated assignments are recorded with resolved scope/genvar values and incorporated by the lowerer for whole-signal, constant bit-select, and constant part-select targets. Active `logic` and `bit` declarations without initializers are lowered when they occur inside scoped static generate blocks; the resulting T-IR names include the generate scope and, for child modules, the instance path. `test_generated_assignment_lowering.ps1` checks one selected generate-if, three generate-for scopes with same-named local signals, packed output-bit assembly, and one child-module declaration. Generate-local parameters, declaration initializers, declarations outside a scoped generate block, and complete SystemVerilog type sizing/sign conversion remain unsupported. `--lower-project` emits a typed expression/equation T-IR slice for supported continuous assignments and limited `always_ff`, `always_comb`, hierarchy, and temporal-property forms. The combinational subset includes nested `if`/`else`, exact `case`, and restricted binary-pattern `casez`, with exact widths and all-path assignment checks. SVA output includes symbolic sequence automata for the bounded subset, fixed and finite bounded ##[m:n] delay ranges, implication alignment, positive bounded repetition, and `$past`; selected `$past` expressions generate data-history shift equations and validity-state equations. Complete SVA sampling semantics and executable property monitors remain unimplemented. Full driver/latch analysis, complete select-bound semantics, complete simultaneous T-IR, SAT, proof checking, and trace replay remain unimplemented. A dedicated T-IR evaluation regression validates generated bit/part-select assignment ordering for ascending/descending ranges, including a parameterized child, plus fail-closed negative cases. `Q3A_SYNTAX_OK`, `Q3A_ELABORATED`, and the current T-IR slice do not imply proof support.
