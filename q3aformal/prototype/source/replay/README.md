# Q3AFormal Bounded Counterexample Replay

`property_replay.hpp/.cpp` independently evaluates decoded SAT traces against the supported T-IR profile. Replay does not consume SAT clauses or bit-blaster evaluation results. It reconstructs signal values from the decoded model, evaluates supported expressions, checks combinational and next-state equations frame by frame, checks assumptions, then verifies the selected assertion failure or cover-goal match.

## Supported trace semantics

Replay covers scalar properties, standalone linear sequence assertions, and linear finite implication assertions using `|->` or `|=>`, constant sequence delays, finite literal or resolved-constant delay ranges `##[m:n]`, positive bounded consecutive repetition, and scalar/linear-sequence/linear-implication cover goals. A bounded delay range is represented by legal endpoint alternatives in the linear matcher. Unbounded delay ranges and non-linear automata are rejected. An implication cover requires a matched antecedent and a complete consequent match; vacuous implication success is not reported as a bounded reachability witness. This is not full IEEE assertion-coverage accounting.

Expression replay supports the operators implemented in the bit-blaster, including the tested mixed-width sizing slice, addition/subtraction with T-IR result sizing, unary two's-complement negation, constant-distance logical shifts and the four-bit prototype `>>>` extension, packed-range-normalized static bit/part selects, and lowered `casez_match`. `>>>` sign-fills only when its left operand is signed; unsigned operands zero-fill. It remains outside the v0.10 declared Phase 0 subset pending a profile amendment. RTL initial state remains unconstrained; generated `$past` validity state follows the T-IR initial-state contract.

The BMC command prints `Q3A_BMC_REPLAY VALIDATED` and `Q3A_BMC_TRACE_SIGNAL` rows only after replay succeeds. If model decoding is inconsistent, an equation or assumption fails, or the selected assertion/cover goal does not match, replay rejects the candidate and the command does not report `BOUNDED_FAIL` or `COVERED`. The optional `--vcd <path>` exports a replay-validated counterexample or cover witness to a Value Change Dump (VCD) file. The optional `--html <path>` creates a self-contained offline SVG waveform viewer from that same validated trace, with signal filtering, frame cursor control, and one-bit/vector value display. Both exporters refuse to overwrite the input manifest or RTL source, and neither creates output when no validated witness exists.

## Induction trace replay

Bounded replay treats a standalone sequence assertion as a required match at each complete property-start frame; an absent match is a failure, not a vacuous implication. The k-induction path replays SAT assignments before saving witnesses. It validates scalar predicates, same-sample `##0` conjunction sequences, one-bit linear assertion sequences, and implication operands using fixed delays, finite bounded delay ranges, and positive bounded repetition. A standalone sequence assertion must match at each property-start frame; for example, `a ##1 q` requires `a` at frame t and `q` at t+1. A false first term is an assertion failure, not a vacuous implication. If a sequence has several legal repetition or delay choices, replay searches them and accepts a property match if at least one complete path matches.

For implications, replay checks every antecedent match endpoint. The consequent starts at that endpoint for `|->` and at the following frame for `|=>`; the reported failure frame is the property-start frame. Assumptions are checked only at starts whose complete maximum horizon fits the finite proof window, matching the encoder's tail truncation. Delayed assertions, implication operands, and assumptions with guarded `$past` are rejected because the current property-level history guard cannot express shifted operand sampling. A validated base trace can establish a reachable `FAIL`; a validated step trace is only a countermodel to k-inductiveness and may be unreachable.

## Limits

This is an independent implementation of the current bounded replay subset, not an independent proof checker. It does not validate unsupported SystemVerilog semantics or establish unbounded correctness. VCD time uses one nanosecond per discrete sample frame; abstract clock events are frame boundaries and clock ports are omitted. No Fast Signal Database (FSDB) waveform is produced. A cover miss in a finite bound is non-conclusive `UNKNOWN`, not `UNREACHABLE`.

`test_property_replay.ps1` checks accepted bounded and induction traces, arithmetic/signedness and shift vectors, and rejection of altered equations, violated assumptions, inconsistent property encodings, invalid candidate frames, invalid step hypotheses, incorrectly initialized history guards, missing cover matches, and antecedent-only implication-cover traces. Mutation checks flip each input, state, and combinational output bit independently at two frames in a valid counterexample (six mutations), corrupt every 3-bit/2-bit addition and subtraction result under four signedness combinations (256 mutations), break the antecedent or consequent of one-term overlapped/non-overlapped covers (four mutations), and break the start, delayed term, or consequent of both `req ##1 ack |-> done` and `req ##1 ack |=> done` cover witnesses (six mutations). Negative timing controls ensure an overlapped consequent cannot match one cycle late and a non-overlapped consequent cannot match at the antecedent endpoint. Replay must reject all corrupted traces. See [T020 replay mutation evidence](../../corpus/results/t020-replay-single-bit-mutation-2026-11-20.md). `test_bmc_arithmetic_shifts.ps1` checks end-to-end addition, subtraction, unary negation, and logical-shift witnesses; `test_bmc_selects.ps1` checks ascending/descending packed ranges and rejection of dynamic or out-of-range selects. Broader profile coverage remains open under T020.
