# Q3AFormal T016 Lowering

The parser retains continuous-assignment spans, `always_comb`/`always_ff` statement trees, and source spans for SVA property declarations/checks. The T016 lowerer builds typed expression trees and emits deterministic JSON under schema label `Q3A-TIR-0.4`, with source locations for signals, constants, equations, expressions, and properties. T-IR 0.4 records independent antecedent and consequent `$past` validity guards. Guard warm-up is calculated from each history-using term's earliest sample offset, so a delayed term can be valid before the sequence start reaches the full `$past` depth. It currently supports restricted continuous assignments, one-clock `always_ff`, `always_comb`, and a limited concurrent SVA subset. Unsized decimal literals are signed and at least 32 bits. RTL-005 covers literal-only decimal expressions and a focused mixed signal/decimal unary/binary +/− expression-tree subset: supported expression trees containing an unsized decimal may use an explicit `assignment_resize` for a narrower destination, and the target width is passed as context to unsized decimal leaves. Regressions check 8-, 16-, and 40-bit contexts across continuous, `always_comb`, and `always_ff` paths with signed and unsigned signals. Direct sized binary, octal, decimal, and hexadecimal literals may use an explicit assignment_resize when the target width differs; extension follows literal signedness and truncation keeps low bits across continuous, always_comb, and supported always_ff assignment paths. General sized-literal context propagation into operator trees, other mixed operators, arbitrary expressions, and general IEEE 1800 sizing remain unsupported and fail closed. Sequential logic accepts nested `if`/`else`, exact `case`/restricted `casez`, nonblocking whole-signal assignments, exact assignment widths except for documented direct sized-literal and decimal-literal conversions, and implicit hold expressions for paths without an assignment. Case labels preserve source-order priority; when one branch assigns a state target more than once, the last nonblocking assignment wins. Combinational logic accepts blocking whole-signal assignments, nested `if`/`else`, exact `case` with constant labels/default, and `casez` with explicit-width binary patterns containing `0`, `1`, `Z`, or `?`; all targets must be assigned on every path. Constant bit/part selects are mapped using elaborated packed-range bounds into least-significant-bit-first T-IR offsets; reversed-direction, dynamic, nested, scalar, and out-of-range selects reject. SVA lowering records `assert`/`assume`/`cover`, named property references, one positive-edge clock, fixed delays, finite constant or resolved-parameter `##[m:n]` delay ranges, `|->`/`|=>`, positive bounded consecutive repetition, `$past` operands/delays, and symbolic linear sequence automata. A bounded delay range is lowered to a linear true-predicate repetition term so the existing bounded matcher can represent each legal endpoint; unbounded delay ranges remain unsupported.

Fixed bit and part selects of explicitly packed parameters and localparams also work in the supported RTL and SVA expressions. The elaborator resolves these selections in constant initializers, widths, overrides, and generate conditions. Lowering folds them to unsigned constants of the selected width. The regression covers ascending and descending declared ranges, negative indices, overrides, and 64-bit selections. The RTL-019 regression lowers an exact-width whole-signal assignment and checks legal 8-bit-to-4-bit assignment-context truncation as an explicit T-IR `assignment_resize` plus a nonvacuous BMC assertion. Duplicate continuous/procedural drivers, generated/select interactions beyond the tested top-level cases, and full source-to-model conformance are covered separately or remain open. Module-port connections retain the exact-width policy under RTL-002. See [RTL-019 diagnostic evidence](../../corpus/results/rtl-019-continuous-driver-diagnostics-2026-11-19.md).

Continuous assignments, complete `always_comb` processes, and the supported single-clock `always_ff` subset can be flattened recursively through parameterized or unparameterized module trees, including static generate-if/for scopes and active whole-signal, constant bit-select, or constant part-select generated assignments with resolved genvar constants. Active `logic`/`bit` declarations without initialization are supported inside scoped static generate blocks; SM-036 checks generate-if, multiple generate-for scopes, and a child instance. Generate-local parameters, declaration initializers, and declarations outside scoped generate blocks remain unsupported. Complete bit/part-select sets are assembled in declared packed-bit order into one full-width T-IR equation; partial coverage and duplicate drivers are rejected. `test_generated_bit_assignment_lowering.ps1` independently evaluates the emitted equations for all 16 four-bit values in ascending/descending ranges, direct/generated part-selects, and a parameterized child, and checks fail-closed cases. Its BMC checks require the combined relation to pass and an intentionally false relation to produce a replay-validated counterexample. Resolved parameter/localparam values are preserved under instance-qualified names. Child-local signals use full hierarchical names such as `u_middle.u_compare.xor_value`. Child input actuals may use the supported expression subset and must exactly match the formal width. Child output actuals may be whole parent-scope signals or connected to constant, direction-matched bit/part-selects of packed parent vectors, including through nested child hierarchy; formal/actual widths must match, and selected bits must cover a driven parent bus exactly once. Generate-variable indices resolve per instance. SM-037 checks direct and wrapped sequential part-select outputs; SM-038 checks direct and wrapped combinational part-select outputs and their assembled bus relation. Child sequential state keeps its full instance path and maps its one-bit positive-edge clock through each parent level. Properties in direct or recursively nested child modules may use inline or named `assert`/`assume`/`cover` checks. Property names carry the complete elaborated instance path; clocks and port expressions are remapped through each wrapper, and generated history-data references plus validity guards retain instance namespaces. `test_child_property_lowering.ps1` checks direct, generated, two-level nested, and three-level generated nested instances with guarded `$past`, assumption-constrained bounded cover misses, bounded pass results, and replay-validated false-property counterexamples on every generated lane. Scalar sequential child outputs may connect to constant parent-vector bit-selects: each child state lane remains a distinct one-bit transition signal and contributes one lane to the full-width bus equation. `test_sequential_child_output_bit_lowering.ps1` checks direct and wrapped generated lanes with passing and replay-validated failing guarded-history properties on all four lanes. Direct and wrapped sequential child output part-selects have focused constant-select coverage in SM-037; direct and wrapped combinational child output part-selects have focused bounded-property coverage in SM-038. Dynamic/indexed output selects and expression-valued output actuals remain unsupported. For sequential logic, the slice supports whole-signal nonblocking assignments, nested `if`/`else`, `case`/restricted `casez`, exact widths, and implicit hold expressions. For combinational logic, case selectors and labels must have exact matching widths, `case` requires a default item, and `casez` labels must be sized binary literals with no X digits. First-match source ordering is preserved. `casez_match` nodes mean `(selector & mask) == (pattern & mask)`. A dependency check rejects combinational cycles across lowered equations. The SVA subset is limited to one clock and one-bit predicates, constant delays, implication, positive bounded repetition, and guarded `$past`; finite positive repetition of supported compound sequences includes exact and ranged counts. Lowering rejects unsupported operators and caps expanded compound sequences at 10,000 terms. [Offset and boundary oracle](../../tests/test_sva_sequence_alignment_oracle.ps1) · [Checked induction and replay](../../tests/test_inductive_sva_implication.ps1) Assignment-context conversion follows the documented subset: RTL-005 unsized-decimal expression sizing and RTL-006 direct based-literal extension/truncation are supported; other expression-context sizing remains explicitly bounded. Unsupported assignment targets or expressions reject rather than being silently resized. It rejects incomplete assignments/latches, blocking assignments in sequential processes, nonblocking assignments in combinational processes, generated local parameters, declaration initializers, declarations outside scoped generate blocks, unsupported hierarchy output forms, multiple drivers, and multiple clocks rather than silently omitting or approximating unsupported behavior.

This output is not the complete canonical transition-system intermediate representation required by the model contract. The supported SVA subset emits symbolic finite sequence automata with explicit start/accept states and transitions carrying predicates, cycle delays, and bounded repetition. The property retains its antecedent/consequent automata and implication mode; executable property monitors and complete SVA sampling semantics are not implemented. The selected `$past` forms create history-data shift equations and a generated validity-state chain with explicit guard metadata. The current implementation caps generated history depth at 65,536 samples as an implementation resource guard; this is not a profile-level language limit. Source-to-model completeness, model hashing, SAT queries, proof checking, and witness replay are not implemented here. The symbolic sequence automata are not proof obligations accepted by a solver and do not establish a property result.

The handshake transition oracle checks the lowered `full` and `data_q` equations against an independent frame equation for all 4,096 combinations of those state values and the relevant reset/handshake inputs. It provides focused evidence for synchronous reset priority and simultaneous updates, not a general proof that all supported source programs are translated correctly.

The `casez` oracle evaluates the lowered masked-match and conditional nodes for all 16 values of the four-bit selector. Its overlapping patterns check that the first source item wins. This is one bounded vector, not complete `casez` conformance.

The history frame oracle checks the two generated history-data stages against six independently specified input samples and confirms a one-stage validity state advances through reset assertions. It checks the history-state equations only; it does not evaluate property pass/fail semantics.

The hierarchy regression lowers named and positional direct-child connections, including child continuous logic, `always_comb`, one-clock `always_ff`, exact-width expression-valued inputs, child-local combinational nets, and resolved parameter/localparam metadata. It checks expression flattening across two hierarchy levels, full hierarchical signal/state paths, synchronous reset and clock mapping through a middle module, simultaneous updates to multiple child registers, parameterized passthrough at widths 2/3/4, two instances of one stateful leaf with isolated state equations, and representative parent output behavior. Focused regressions now validate one generated child instance, active whole-signal generated assignments in top and child scopes, and active scoped `logic`/`bit` declarations with generate-if/for and child-instance paths; generated bit/part-select assignment lowering and scalar direct-child output bit-select mapping have focused regression coverage. Generate-local parameters, declaration initializers, and declarations outside scoped generate blocks remain unsupported. Scalar sequential child outputs may connect to constant parent-vector bit-selects: each child state lane remains a distinct one-bit transition signal and contributes one lane to the full-width bus equation. `test_sequential_child_output_bit_lowering.ps1` checks direct and wrapped generated lanes with passing and replay-validated failing guarded-history properties on all four lanes. Direct and wrapped sequential child output part-selects have focused constant-select coverage in SM-037; direct and wrapped combinational child output part-selects have focused bounded-property coverage in SM-038. Dynamic/indexed output selects and expression-valued output actuals remain unsupported.

The separate-process regression lowers two top-level `always_ff` processes clocked by the same signal. Its independent oracle checks all 16 old-state/reset/input combinations and confirms that each transition equation reads the shared pre-edge state.

The fixed-width packed-concatenation regression checks source-order T-IR operands and widths for a three-member `{a,b,c}` expression, evaluates all 64 input combinations against an independent packed-value equation, and proves/reopens a bit-slice relation. This closes the RTL-015 concatenation-specific evidence for the bounded grammar; it does not close separate context-dependent expression-sizing rules.

RTL-006 direct sized-literal assignment resizing is checked by test_sized_literal_resize.ps1 and its source-level vector: signed/unsigned based literals are checked for all four bases, zero/sign extension and truncation are exercised in continuous, always_comb, and always_ff assignments, and bounded SAT assertions check the resized values. Mixed sized-literal operator trees remain unsupported.
